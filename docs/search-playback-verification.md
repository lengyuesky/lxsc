## 已实现

- 将管理员「搜索测试」升级为所有登录用户可用的「搜歌」，支持聚合及单平台搜索，展示时长并提供播放、收藏入口。
- 全局播放器支持播放/暂停、上一首/下一首、进度、音量与静音；按点击时的列表快照连续播放，保留重复项，队尾停止，页内导航不中断播放。
- 网页播放仅使用网页登录 Cookie，复用现有媒体逻辑，遵循直连或代理设置；不扩大 `/rest` 的 Cookie 认证范围，也不在直连失败时自动切换代理。
- 支持收藏到可编辑歌单，以及新建歌单并立即收藏；新歌置顶、按 ID 去重、单歌单最多 2000 首，元数据与歌单关系事务提交。
- 保留歌单内「加入草稿、手动保存」流程；未保存草稿保护及版本冲突检查防止覆盖并发更新，旧完整替换接口继续支持顺序和重复项。
- 退出或确认会话失效后释放音频、队列和请求，忽略旧搜索、详情及播放回调。

## 真实 Chromium 验收

使用临时数据库、本机隔离服务及合成 WAV，不读取生产数据库，不调用外部音乐平台。以下 12 项全部通过：

1. 普通用户搜歌、真实播放、队列及页内导航。
2. 拖动进度条后保留焦点，进度仍跟随实际播放。
3. 即时收藏、重复去重、新建收藏及公开歌单只读播放。
4. 草稿保护及其他页面收藏引起的 HTTP 409 不丢数据。
5. 收藏完成后，旧详情不能覆盖新状态和新草稿。
6. 保存完成时同步解除已打开收藏弹窗的草稿阻止。
7. 保存途中继续编辑，不错误采纳其他收藏版本；信息保存不改变歌曲草稿基线。
8. 详情等待期间的新编辑不被旧读取清除。
9. 直连失败停止且不自动代理，会话失效释放播放器。
10. 空白新搜索取消旧结果。
11. 退出取消旧详情，不在登录页面提示取消错误。
12. 代理真实播放、Range，以及移动端深色布局。

复现命令及 Playwright/Chromium 路径配置见 [README 开发验证](../README.md#开发验证)。
