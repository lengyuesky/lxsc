## 用户确认的行为

- 飞牛新建歌单默认私有，归当前用户；沿用共享所有者/管理员编辑权限，公开歌单仅放开读取。
- 新增曲目按选中顺序置顶，相同 ID 不重复插入，旧重复项不重排；移除所选歌曲时删除同 ID 的全部位置。每歌单写入上限 2000 首，批量校验失败整体回滚。
- 歌曲收藏使用共享个人收藏表，独立于歌单成员关系。主动保存搜索歌曲后保留元数据及稳定引用；仅浏览搜索不持久化结果。
- 下载只保存到 App 本地，不自动收藏、加入歌单或记录收听。原始音质沿用用户的音源质量与现有降档，服务器不转码或保存音频。
- 完成的本地下载独立于收藏与歌单。库外搜索歌曲的未完成下载须保持有效搜索会话；会话过期、重新登录或服务重启后需要重新搜索。持久收藏或可读歌单可用于重新发起完整下载。
- 安全续传需要同一音频表示的校验条件。身份或授权失效时失败，允许删除失败任务后重新完整下载。

## 实现与原版协议证据

以下路径以 `/music/api/v1` 为前缀。写请求方法、参数名称由原版 App 本轮实际请求核对；并未将社区客户端或代理实现的模拟结果当作原版下载证据。

| 能力 | 方法及路径 | 请求关键字段 |
| --- | --- | --- |
| 默认/自选歌单封面上传 | `POST /static/cover/playlist` | multipart `file`，返回 `data.coverId` |
| 创建歌单 | `POST /playlist/create` | `name, coverId` |
| 改名 | `POST /playlist/edit` | `guid, name, coverId` |
| 删除歌单 | `POST /playlist/delete` | `guid` |
| 添加/移除曲目 | `POST /playlist/add-track`、`/playlist/remove-track` | `guid, trackGUIDs` |
| 收藏/取消收藏 | `POST /favorite-track/create`、`/favorite-track/delete` | `trackGUID` |
| 原始下载 | `GET /download/track` | `guid`，原版从 `Range: bytes=0-` 开始 |
| 下载详情 | `GET /download/track/detail` | `trackGUID`，原版另传 `lan` |
| 原始下载后的任务清理 | `POST /download/track/transcode/delete` | 本轮原版只有 `lan`，没有下载任务 ID |

标准档的转码准备、状态及文件接口仍明确拒绝。原始下载后的空转码任务清理是幂等空操作，不产生或假冒服务端任务。

默认封面是原版创建歌单的前置步骤：首轮实际因上传端点 404 显示“上传失败，请重试”。补齐后上传、创建、读取封面及改名均通过。JPEG/PNG 完整解码校验，最大 5 MiB、1600 万像素；当前不提供 WEBP 解码器，明确拒绝 WEBP 上传。客户端仍显示其自身格式提示，服务端拒绝不会返回假成功。

数据库版本 8 增加 `playlist_covers` 与歌单引用；保存用户归属和图片，不保存音频。封面上传复用共享工作并发限制，交付复用大图传输限制；未绑定上传保留 24 小时，单用户最多 10 个待用封面。删除资产时清空引用以恢复自动封面。

歌单/收藏元数据、关系和协议标识在同一事务中保存；事务内再次校验源曲权限、用户状态及目标歌单权限。临时搜索授权仍按会话及期限复查。旧成员键与上游规范 ID 不同的歌曲保留实际成员键，避免移除返回成功却不生效。

## 下载交付与失败边界

下载复用共享媒体的真实解码验证、取链、降档、并发限制和管理员直链/代理设置，并关闭播放元数据持久化。下载路径采用长媒体 I/O 预算，普通请求 60 秒总期限不截断已开始的文件。

原版下载器曾把带 JSON 正文的 404/502 错误列为“已下载”，实际不能播放。二进制下载失败现中止 HTTP 流，不交付错误正文；代理正文中断也中止流。原版重测显示“网络错误”，残缺文件未进入已下载。

代理续传按会话保留 30 分钟、全站最多 4096 份表示描述，内容为实际响应类型、完整大小、强 ETag 或 Last-Modified，以及音源、实际档位和媒体地址的摘要。没有音频、原始 URL 或票据值。原版不发 If-Range 时补上该会话最初的表示校验条件；HEAD 不替换已经开始的下载表示。

续传还校验媒体身份摘要、响应 ETag/Last-Modified、完整 Content-Range 和长度，拒绝上游忽略范围的 200 响应、错误起点/终点或全长。同会话并发取得不同表示时禁止自动续传，要求完整重下。签名地址改变也会保守拒绝续传。直链模式无法在本站验证客户端追加的最终字节，非零续传明确失败；管理员强制 302 不会被转换为代理。

下载详情只使用实际交付验证过的容器与大小，不继承尚未验证的位深、采样率、编码或码率。未知真实大小保持未知。
