# 优化与功能验收

本轮保留 Go 单进程、SQLite 与无框架网页结构。没有更改音源 SDK、运行依赖或播放模式契约。

## 交付范围

六项功能入口与行为：

| 功能 | 入口 | 已实现行为 |
|---|---|---|
| 1. 完整网页队列 | 搜索「加入队列」、歌单歌曲「＋」、播放器「队列」 | 下一首/末尾入队、移动/移除、循环/随机、按账号恢复；指定下一首优先于随机选择 |
| 2. 歌词与系统媒体控制 | 播放器「歌词」、系统媒体面板 | 原文与翻译、当前行高亮、点击定位、媒体信息、播放暂停和切歌 |
| 3. 失效歌曲修复 | 歌单「换版本」「歌曲历史」 | 候选排序、试听、替换草稿，保存前保留原列表，最多10次，可预览并恢复到草稿 |
| 4. 在线歌单订阅 | 歌单「订阅更新」 | 源地址、差异预览、只追加更新、可选每日更新、失败重试、并发版本检查 |
| 5. 音源健康面板 | 管理员「音源」 | 一小时内最多100次样本的成功率、耗时、降级、失败类别；不把解析成功当作客户端播放成功 |
| 6. 智能歌单 | 搜歌「个人智能歌单」 | 近30天常听、本月最爱、久未听的加星收藏、歌手收藏，可播放和另存私有歌单 |

歌曲历史仅由网页的歌曲列表保存流程产生，历史保留期间原歌曲元数据不会被无引用清理删除；历史不对普通公开歌单访客开放，删除歌单时一并删除。超过2000首的旧客户端歌单不生成历史快照，但仍允许缩减到网页上限。数据库迁移及备份清单版本现为3，支持读取旧版备份。

- 收藏/取消收藏、收藏列表与播放历史写入失败明确报错，避免假成功。
- API Key 摘要迁移、设备名称、有效期、列表、最近使用与逐个撤销；关闭管理弹窗、退出登录清空密钥展示。
- 版本化事务迁移，Subsonic 队列、歌曲评分、当前用户正在播放。
- 网页队列编辑、下一首加入、随机与循环、本机恢复（默认暂停）、同步歌词与系统媒体控制。
- 平台独立搜索分页与重试，保留已显示结果的顺序和按钮。
- 备份错过计划补跑、失败退避、最近成功上传与重试时间。
- 近一小时音源解析健康面板，不记录媒体地址或搜索词。
- 歌曲其他版本候选、试听与替换草稿；沿用保存时的并发版本校验。
- 歌单订阅来源、差异预览、只追加更新、每日可选自动更新；源端变化/本地变化均检查版本，失败不覆盖原歌单。
- 基于个人统计/加星收藏的智能歌单、另存为私有歌单。
- 显式预览和分批清理原始播放历史；听歌统计及去重记录不删除。

## 升级边界

迁移自动执行，但本次没有部署或操作生产数据库。旧API Key原文仍可登录，数据库中保存的是摘要。新版备份清单版本为3，旧版备份可向前恢复；旧程序拒绝新版备份，不能直接将程序降级到摘要迁移之前。

网页快照只保存歌曲信息和进度，不保存口令、密钥或媒体直链；账号退出清除，浏览器存储失败不影响播放。网页恢复不自动开始播放，跨设备队列同步由 Subsonic 客户端自行调用对应端点。

订阅使用平台解析器生成请求，不接受任意URL直连；自动更新每分钟最多10个到期歌单、逐个处理、每个45秒，复用现有用户限流。源端读取不完整、歌曲超过上限或版本冲突均保留本地内容。

本轮没有统计明细自动归档、跨平台自动替换或音源自动熔断：对应操作可能改变统计去重或歌曲版本，当前提供显式历史清理、人工试听确认和健康证据。

## 验证方法

2026-09-30 最新本地验证结果：全量 Go 测试、竞态检测和 vet 通过；58项 Node 测试通过；58项隔离浏览器验收全部通过。新增测试覆盖歌曲历史事务回滚、权限隔离、10次保留上限、原元数据清理保护、北京时间月界，以及指定下一首在随机模式和刷新恢复后仍生效。最终播放器细节另行通过单元测试与六项功能浏览器复验。浏览器使用合成音源，不代表外部音乐平台在部署环境中的可用性。

原有听歌统计取消测试存在清理时序假设：等待者离开合并表不代表执行名额已经释放。验收现等待真实工作与排队清理结束，再验证恢复；未放宽生产限流。

- `bash scripts/check.sh --race`：Go测试、竞态检测、vet、Node测试、diff检查。
- `node tests/web/browser.cjs`：隔离数据库、合成音源与WAV；包含原有回归与新功能浏览器验收。
- 局部复验可指定 `LXSC_BROWSER_FILTER=队列编辑` 等名称片段；发布验收应不设置过滤条件。
- 新增后端测试覆盖旧密钥升级与再次打开、到期/撤销/账号隔离、队列重复项与持久化、JSON/XML协议、收藏错误返回、订阅权限/冲突/本地删除保护、备份跨日/跨周补跑、历史分批清理和统计保留。
- 新增播放器单元测试覆盖暂停恢复、队列移动不重载音频、移除当前歌曲保持暂停意图、循环与随机边界。
- 浏览器验收覆盖队列与歌词、分页、订阅预览/确认、版本替换草稿、密钥完整生命周期，保留桌面和移动端截图。

本地 Go 1.27.0，Node 26.10.0，Playwright 1.58.2 Chromium；CI继续使用仓库固定Node 24.21.0。Node 26下载浏览器后的解包存在工具兼容问题，本地使用同一下载归档解压并指定可执行文件，未更改锁文件。
