# 飞牛协议隔离，音乐用户与业务共享

原版飞牛音乐 App 的协议与现有 Subsonic 协议不能直接等同，而 lxsc 已有集中式音乐核心、用户和歌单权限。选择新增独立的飞牛协议适配层，负责客户端请求、响应和会话协议，底层复用现有音乐核心与数据库，保留现有 `/rest` 和网页接口。飞牛 App 的“音乐独立账号”登录映射到同一套 lxsc 用户与权限，不另建飞牛专属账号或音乐数据体系，也不复制取链、歌单和权限业务，以避免账号数据分裂及协议变化污染现有客户端。

## 后果

- 同一 lxsc 用户通过不同兼容客户端访问同一份被授权的收藏和歌单；私有歌单隔离与公开歌单权限必须保持现有语义。
- 首版不实现 NAS 系统账号登录，不借用管理员身份代替普通用户认证。
- 现有媒体处理部分位于 Subsonic 层；若飞牛协议需要复用，应抽出共享能力并回归现有客户端，不以内部 HTTP 转发或复制处理器代替业务分层。
- 本决策确定代码与数据归属，不假定飞牛登录必然使用某一种令牌、Cookie 或握手格式；这些细节以原版客户端的可复核协议证据为准。
