# 保存音源调度经验，保留原样本时效

自动排序依赖音源、平台和动作各自的近期调用及媒体样本，音源页诊断汇总与最终排序分数都不足以在重启后正确重算。选择保存原始样本、连续失败与冷却／限流截止时间，继续采用原有的 10 分钟样本有效期并计入停机时间，以免把陈旧故障或速度判断永久固化为音源优先级。

音源 ID 标识同一份管理记录，脚本内容指纹标识产生经验的脚本。相同内容停用再启用保留有效经验，脚本内容改变或连续 10 分钟无新样本时重新学习；旧脚本的迟到结果不能覆盖新脚本状态。完整备份前与退出时补写状态，恢复按当前时间判定有效期，运行中的调用和探测锁不恢复为占用状态。
