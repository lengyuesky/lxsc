# 原版飞牛音乐 App 的独立服务端边界

飞牛音乐官方资料允许原版 App 通过 IP 地址或域名连接服务器，但尚未证明第三方独立服务端能完成必需的握手、认证和音乐接口交互。选择让 lxsc 在普通 Docker/Linux 环境中独立服务原版 App，保留现有在线曲目、收藏和歌单，不依赖真实飞牛 NAS、fnOS 系统账号或飞牛云中继，也不新增本地音频扫描、上传和服务端音频落盘。排除借真实 NAS 完成认证或透传官方音乐后端的桥接路线，避免以隐藏部署依赖的方式宣称兼容。

## 后果

- 第一阶段必须在原版 App 中验证登录、既有歌单与曲目展示、实际播放、进度拖动和切歌；接口成功或拿到重定向地址不能替代实际播放验收。
- 在线搜索、收藏写入、歌词和离线下载不属于第一阶段通过条件；通过最小协议闭环后仍须验证真实在线音源。
- 只对实际验收过的客户端平台与具体版本组合声明兼容，客户端升级后重新验证。
- 本决策记录目标边界，不代表当前已兼容；具体协议、鉴权和媒体交付方案仍待确认。若必需机制无法独立实现，明确报告限制，不以依赖真实 NAS 的桥接结果作为达标证据。

## 依据

- [飞牛音乐官方隐私政策](https://www.fnnas.com/music_privacy)，于 2026-10-30 核查：支持手工 IP 地址、域名或 FN ID 连接，音乐账号独立于 NAS 账号；这些事实不等同于独立服务端兼容证明。
